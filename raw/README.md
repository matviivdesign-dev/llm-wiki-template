# raw/ — джерела

Сюди пише власник, Claude тільки читає. Файли тут імутабельні: не редагуються і не видаляються після ingest,
бо на них посилаються сторінки wiki.

## Правила

- Назва файлу: `YYYY-MM-DD-<slug>.md`. Дата — коли джерело з'явилось (запис, розмова, стаття), не коли скопійовано.
  Щоденник — просто `YYYY-MM-DD.md` у `journal/`.
- Одне джерело на файл: одна стаття, одна сесія, одна розмова, одна глава.
- Перші рядки файлу: звідки (URL, книга, хто говорив), коли, за яких обставин. Далі зміст як є.
- Картинки — у `assets/`, в Obsidian це attachment folder.
- Великі файли (транскрипти на сотні КБ) — нормально, але розбивай по сесіях чи главах, щоб summary-сторінка
  відповідала одному файлу.

## Куди що

| Папка | Що |
|---|---|
| `journal/` | щоденникові записи |
| `articles/` | кліпнуті статті (Obsidian Web Clipper кладе сюди) |
| `books/` | нотатки й цитати з книжок |
| `podcasts/` | транскрипти, нотатки з подкастів і відео |
| `notes/` | дампи думок, ідеї, розмови, Capture з чату |
| `projects/` | усе по конкретному проекту: сесії, рішення, дослідження |
| `assets/` | картинки |
